# AI 新闻封面选择设计

## 目标

让个人报告第 3 页的两条 AI 新闻获得适合 16:9 放映的封面，同时始终允许人工覆盖自动选择。

## 决策

1. 抓取原文时收集正文与 OG 图中的多个候选，不再只返回第一张命中的图片。
2. 按正文位置、像素尺寸、横向封面适配度、`alt` / 图题与新闻标题的词语重合度评分；Logo、二维码、广告与极端比例图片淘汰。
3. 生成新闻后，卡片保存已选封面与其余可换候选。用户可在候选窗口上传原图，或在已生成新闻中循环切换自动候选。
4. 若本地配置了 OpenAI 兼容的图像模型，正文没有合适封面时可请求一张无文字 16:9 主题图；没有该配置时保留无图的演示底板并给出上传入口，新闻摘要生成不受影响。
5. 图像地址与用户的新闻数据一起按账户、按周保存；历史归档保留当时的封面快照。

## 不做的事

- 不抓取搜索引擎结果页或随机图库，避免相关性、版权与稳定性不可控。
- 不将图像生成能力绑定到当前用于摘要的 DeepSeek 文本模型。
