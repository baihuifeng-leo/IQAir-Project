# 自定义页幻灯片母版设计

## 目标

将当前第四页顶部的品牌元素从可拖动正文内容迁移为统一的幻灯片母版；每个新建自定义页都自动拥有一致的顶部标识、分隔线与可编辑标题区。

## 方案取舍

1. 推荐：数据化母版层。品牌标识、横线与标题区由渲染器固定生成，不占正文元素列表，也不能被拖动或删除；适用于每页一致的周报版式。
2. 保留为普通元素并在新建页复制。实现最简单，但复制后的元素仍会被误移动、误删或叠放，不符合“母版”心智。
3. 允许每页单独配置完整母版。灵活度最高，但增加编辑入口和状态复杂度；目前没有必要。

采用方案 1。

## 母版布局

- 画布保持 1280 × 720。
- 左上：现有左侧品牌图标，固定在 `x=0, y=2`，使用原素材。
- 标题区：从 `x=84` 开始，位于横线之上；默认文字为“未命名页面”，可单击或双击直接编辑，标题不再作为普通文字框保存。
- 右上：现有右侧品牌标识，固定在 `x=1180, y=9`，使用原素材。
- 分隔线：将现有横线图片替换为 CSS 绘制的全宽细线，起点 `x=70`、终点 `x=1264`，纵向位置 `y=68`。这避免低分辨率图片放大后的锯齿与比例漂移。
- 正文安全区域：从分隔线下方开始；新建文字和图片的初始位置避开顶部母版区。

## 数据与迁移

- 自定义页新增 `title` 字段；历史页面优先将其顶部文字元素的内容迁入 `title`。
- 当前第四页中四个顶部普通元素（左图、标题文字、右图、横线图片）在第一次加载时识别并清除，避免与母版重复。
- 用户现有正文元素不得删除。新建页面写入默认标题并显示同一母版。

## 呈现、导出与编辑

- 日常编辑、放映模式和 PDF 导出使用同一母版渲染逻辑，确保比例一致。
- 标题在编辑态可直接输入；放映和 PDF 中只展示文本，不显示编辑边框或工具条。
- 母版图形不成为可选元素，正文的置顶、置底和删除操作不会影响母版。

## 错误处理与测试

- 没有历史标题时使用“未命名页面”。
- 迁移必须幂等：刷新或再次保存不重复删除任何正文元素。
- 添加静态回归测试，覆盖新页面默认标题、母版渲染、顶部遗留元素迁移及 PDF 渲染路径。
