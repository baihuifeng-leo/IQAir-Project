# 周报档案母版冻结设计

## 背景

自定义页母版目前由前端在渲染时无条件叠加。历史档案保存的是页面元素，但未保存母版版本；因此后来新增或调整左上标识、右上 Logo、横线时，会直接覆盖旧档案页面的顶部内容。

## 目标

1. 已归档的报告在视觉上冻结，不受后续母版代码、样式或素材变化影响。
2. 新归档的报告记录当时所用母版版本。
3. 当前已有的 `2026-07-27` 与 `2026-08-03` 档案不再叠加母版，完整展示已保存页面元素。
4. 只有用户主动创建历史修订版时，才允许将该修订版迁移到当前母版。

## 设计

### 母版版本

报告快照的 `report` 增加 `slideMasterVersion`。当前工作区使用 `1`；归档快照在创建时显式保存该值。归档打开后，前端将该值传入自定义页渲染器。

渲染器按版本选择母版：

- `1`：使用当前固定资源与固定版式的母版。
- `0` 或缺失：不渲染任何母版层，只渲染快照内保存的页面元素。

母版样式以版本选择器隔离，后续新增母版必须定义新版本，不能修改既有版本的资源路径、位置与样式。

### 旧档案修复

生产数据中的所有现有归档快照标记为 `slideMasterVersion: 0`。这项一次性迁移只写档案快照，不改变实时报告、新闻、数据页或自定义页元素；执行前创建生产数据备份。

### 修订版

创建修订版时默认继承原档案母版版本，保证修订不会意外改变历史视觉。后续若提供“升级母版”动作，必须作为明确的版本迁移操作，而不是隐式渲染行为。

## 验证

新增回归测试覆盖：归档快照保存版本 `1`；缺失版本的历史页不创建母版 DOM；当前母版仅在版本 `1` 时渲染；旧档案迁移仅追加版本字段而不修改页面元素。部署后检查两份历史档案版本为 `0`，并确认放映与 PDF 均不渲染母版覆盖层。
