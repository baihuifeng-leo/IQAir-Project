# 滤芯详情页重置周报页设计

## 目标

在个人报告第五页用一张放映友好的页面说明滤芯详情页的重置进展：完整呈现旧版详情页长图，同时展示已完成的新版模块素材与内容结构化成果。

## 页面叙事

页面从左至右表达“旧页面 → 文案归类与模块标准化 → 新页面模块”。

- 左侧：旧版 V5-Cell 长图按完整原始比例缩略显示，保留其连续长图特征。
- 右侧：新版模块以四张完整等比卡片展示，分别对应购买与验收、适配机型、寿命与服务、参数与产品价值。
- 页首：说明本周已完成文案梳理、区域分类、规范化与模块输出。
- 页尾：给出演讲提示——新版按“了解 → 适配 → 使用 → 购买”的决策路径组织内容。

## 放映交互

页面中的旧长图和每一张新模块卡片均是查看入口。

- 放映模式点击任一素材，打开原生 `dialog` 浮窗，覆盖当前页面而不切换报告页。
- 旧版长图在浮窗中按原始比例显示，并允许垂直滚动完整查看。
- 新模块在浮窗中按原始比例完整显示；当尺寸超过视口时允许滚动查看，不裁切图片内容。
- 点击浮窗外部、关闭按钮或按 `Esc` 均关闭浮窗并返回第五页。
- 非放映编辑模式使用相同的查看方式，方便核对源素材。

## 数据与素材

- 第五页复用现有自定义页数据模型，作为 `pg_wfw6zso`（“滤芯详情页重置”）的内容。
- 用户提供的旧版素材：`temp/滤芯详情页/[Product Page] 20210929 V5-Cell.jpg`。
- 用户提供的新版模块素材来自 `deliverables/modules/`；导入报告后使用应用的 `/uploads/` 地址持久化。
- 页面在 1280 × 720 的报告放映画布中保持一屏；任何需要阅读细节的素材通过浮窗查看，而不压缩页面文字到不可读尺寸。

## 边界与验证

- 不改动前三页系统页与第四页自定义页。
- 不改变现有 PDF 导出逻辑；PDF 保留第五页的主视觉，不包含交互浮窗。
- 自动化回归覆盖：第五页配置存在、所有素材元素可被点击查看、旧长图与新模块采用完整比例的 `object-fit: contain` 呈现、Esc/遮罩关闭浮窗。
